# Vaisseaux arc-en-ciel

Vaisseaux (`Ship extends Vehicle`) en errance, réglables depuis un panneau repliable (nombre 1–200, vitesse max, accélération max) ; touche D / case à cocher synchronisées pour le debug (vecteurs vitesse en rouge) ; halo radial arc-en-ciel (`RainbowGradient extends Vehicle`) qui suit la souris avec `arrive()`, entièrement réglable. Spécification : `1-Specification.md`.
